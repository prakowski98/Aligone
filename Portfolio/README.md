# 🚀 Modern Portfolio Website

A stunning, cyberpunk-themed portfolio website built with cutting-edge technologies. Features dark mode design with neon accents, smooth animations, and an immersive user experience.

## ✨ Features

- **🎨 Cyberpunk Design**: Dark theme with neon blue, purple, and pink gradients
- **⚡ Smooth Animations**: Built with Framer Motion for fluid, eye-catching transitions
- **🌊 Matrix Rain Effect**: Animated background with falling characters
- **📱 Fully Responsive**: Optimized for all devices and screen sizes
- **🎯 Interactive UI**: Hover effects, glitch animations, and dynamic cursor glow
- **⚙️ Modern Stack**: React, TypeScript, Vite, TailwindCSS

## 🛠️ Tech Stack

- **Frontend Framework**: React 18
- **Language**: TypeScript
- **Build Tool**: Vite
- **Styling**: TailwindCSS
- **Animations**: Framer Motion
- **Icons**: React Icons
- **Fonts**: Inter, JetBrains Mono

## 🎭 Sections

1. **Hero** - Eye-catching introduction with typing effect and animated background
2. **About** - Terminal-style bio and feature cards
3. **Projects** - Showcase of featured projects with live demos
4. **Skills** - Interactive skill bars with proficiency levels
5. **Contact** - Contact form and social media links

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd Portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit `http://localhost:5173`

## 📦 Build for Production

```bash
npm run build
```

The optimized production build will be in the `dist` directory.

## 🎨 Customization

### Colors

Edit `tailwind.config.js` to customize the color scheme:

```javascript
colors: {
  cyber: {
    dark: '#0a0e27',
    darker: '#050814',
    blue: '#00d9ff',
    purple: '#b537f2',
    pink: '#ff006e',
    green: '#00ff88',
  }
}
```

### Content

Update the following files to personalize your portfolio:

- `src/components/Hero.tsx` - Your name and title
- `src/components/About.tsx` - Bio and skills
- `src/components/Projects.tsx` - Your projects
- `src/components/Skills.tsx` - Your tech stack
- `src/components/Contact.tsx` - Contact information
